Portal guide & rules

The Dataset Version Portal lets teams publish datasets, keep every version, and get them reviewed before use. You are signed in as .

Roles & permissions

USER Data contributor

Creates and maintains datasets.

Can

  • Upload a dataset with a data file (file is required)
  • Add title, subtitle, description, tags and license
  • Upload new versions of their own datasets
  • Edit and submit their own drafts for review
  • Browse, search, preview and download any dataset

Cannot

  • Approve or reject datasets
  • Edit other people's datasets
  • Delete datasets

REVIEWER Quality gatekeeper

Decides whether a dataset is ready for use.

Can

  • Browse, preview and download every dataset
  • Approve datasets that are In review
  • Reject with a comment - the dataset returns to Draft
  • Use the "In review" filter as a review queue

Cannot

  • Upload datasets or versions
  • Edit dataset details
  • Delete datasets

ADMIN Administrator

Manages the whole portal.

Can

  • Everything a USER can do, on any dataset
  • Approve or reject other people's datasets
  • Delete a dataset and all its files

Cannot

  • Approve their own uploads (four-eyes rule)
  • Upload a version while a dataset is In review (locked)

Dataset lifecycle

DRAFT

The owner uploads files, edits details and adds versions. Nobody else needs to act yet.

➔
IN_REVIEW

The owner submitted it. The dataset is locked and a reviewer must decide.

➔
APPROVED

A reviewer approved it. A rejection sends it back to Draft with the reviewer's comment.

Rules

  1. A dataset cannot be reviewed by the person who uploaded it.
  2. Uploading a new version of an approved dataset moves it back to Draft so the change is re-approved.
  3. Every version keeps its own file, size, SHA-256 checksum, notes, author and download count. Old versions are never overwritten.
  4. Allowed files: csv, tsv, json, xml, txt, xlsx, xls, parquet, zip, gz, png, jpg. Maximum size is 100 MB.
  5. CSV and TSV files get an automatic preview with column types and row count.
  6. Only admins can delete datasets; deleting removes all stored files.

Writing a good dataset page

Like on Kaggle, a well-described dataset is easier to trust and reuse. The usability score (out of 10) rewards a complete page:

ItemPointsTip
Descriptionup to 380+ characters: what it contains, source, columns, how to use it, what the target is.
Subtitle1One clear line (10+ characters).
Tags2At least one tag so people can find it.
License2Pick a real license (anything except "Unknown").
Data file1A file is attached to the latest version.
Approved1A reviewer has approved it.
