# Contributing

## Branches
- main: stable, released code only
- develop: integration branch, all features merge here first
- feature/<short-name>: one branch per feature, e.g. feature/dataset-upload
- fix/<short-name>: bug fixes

## Commit messages
- feat: a new feature
- fix: a bug fix
- docs: documentation change
- chore: setup or maintenance
- test: adding or changing tests

## Pull requests
Open a pull request from your feature branch into develop.
At least one review comment is required before merging.
